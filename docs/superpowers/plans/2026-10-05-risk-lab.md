# Risk Lab Implementation Plan

**Goal:** Build the approved Chinese-first bilingual risk decision dashboard and deploy its static web folder to Vercel.

**Architecture:** Export the existing numeric XGBoost ensemble and MinMaxScaler to a compressed binary artifact. A browser module performs the same engineered-feature calculation, float32 tree traversal and multiclass softmax. Operational advice is an independent, explicitly rule-based layer. No shipment data leaves the browser.

**Tech Stack:** Python export, native JavaScript modules, CSS, Node test runner, static Vercel hosting.

- [x] Model export: `scripts/export_browser_model.py` writes `web/model/model.bin.gz`, `metadata.json`, and Python reference fixtures in `tests/browser-reference.json`. Reject unsupported objectives and categorical splits rather than silently approximating.
- [x] Test first: `web/tests/domain.test.mjs` checks feature and probability parity against all Python fixtures, invalid inputs, inventory-zero handling, scenario actions bounded to original ranges, cost break-even formula and report contents. Run `node --test web/tests/*.test.mjs` before and after implementation.
- [x] Domain modules: `web/domain.mjs` defines input configuration, presets, feature formulas, inference and safe validation. `web/advice.mjs` defines bilingual operational rules, scenario changes, explicit cost assumptions and Markdown report.
- [x] Interface: `web/index.html`, `web/styles.css`, `web/app.mjs` provide grouped sliders and numeric fields, original scenarios, prediction distribution, route animation, pinned baseline comparison, action cards, editable business inputs, methodology and bilingual export. Loading/error states never manufacture predictions.
- [x] Verification: run Python existing tests; generate deterministic reference data; run browser parity and action/cost tests; run a local static server and inspect actual browser interactions including language, presets, sliders, actions, baseline and report export. Check narrow layout and reduced-motion CSS.
- [x] Documentation: `docs/business-logistics-analysis.md` contains the operational reasoning, business formulas, field ambiguity, synthetic-data and non-causal limitations. `web/README.md` explains local use, export and deployment. Preserve existing README edits.
- [x] Deployment: link only the `web` folder to a new `datathon-supply-chain-risk-lab` Vercel project, deploy, then verify the production URL and model assets. Record test and deployment evidence.
